# ZlCosmetics

Custom cosmetics for Minecraft — capes, shoulders, hats, outfits, accessories and more. Free, forever.

ZlCosmetics is a rebranded and maintained build of the Cosmetica mod, packaged for many Minecraft versions across Fabric, Forge and NeoForge.

## Downloads

Grab the jar for your Minecraft version from the [Releases](../../releases) page.
